# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-02

### Added

- Interactive 3D globe demo powered by @aeryflux/globe
- Surface switching between dark, green, and white modes
- Country visibility toggle and data-driven highlights
- WebGL fallback for unsupported browsers
- Fullscreen globe layout with intro animation and horizontal devtools
- Mobile responsive layout
- CI workflow for typecheck and build (ci.yml)
- GitHub Pages deployment workflow (deploy.yml)
- Live demo at https://aeryflux.github.io/globe-demo/
