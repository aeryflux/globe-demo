# Contributing to globe-demo

Thank you for your interest in contributing to the @aeryflux/globe demo application.

This repository is a demonstration app for the [@aeryflux/globe](https://github.com/aeryflux/globe) package. It showcases the 3D globe component in a standalone React + Vite project deployed to GitHub Pages.

## Getting Started

### Prerequisites

- Node.js v22 or later
- npm

### Development Setup

1. Fork and clone the repository:

```bash
git clone https://github.com/aeryflux/globe-demo.git
cd globe-demo
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

## Pull Request Guidelines

- Create a feature branch from `main` (e.g. `feat/my-feature` or `fix/my-fix`).
- Keep changes focused and minimal. One concern per PR.
- Follow the existing code style and TypeScript conventions.
- Ensure the project builds without errors before submitting: `npm run build`.
- Write clear commit messages using the conventional format:

```
feat(scope): description
fix(scope): description
chore: description
docs: description
```

- All PRs target the `main` branch.
- English only for commits, issues, and PR descriptions.

## Reporting Issues

Open an issue on GitHub with a clear description of the bug or feature request. Include steps to reproduce if reporting a bug.
